# ai-apps

## [WebClipboard.online](https://webclipboard.online/)

Free online clipboard: paste text on one device, get a 6-digit code, short link and QR code, and open it on any other phone or computer. No sign-up, optional end-to-end encryption, auto-expiry, in 30 languages.

Also free, in the browser: [QR code generator](https://webclipboard.online/qr-code-generator/), [Wi-Fi QR code](https://webclipboard.online/wifi-qr-code-generator/), [share code online](https://webclipboard.online/code-share/), [ChatGPT to Word](https://webclipboard.online/chatgpt-to-word/), [Markdown to PDF](https://webclipboard.online/markdown-to-pdf/), [word counter](https://webclipboard.online/word-counter/), [token calculator](https://webclipboard.online/token-calculator/) and [more tools](https://webclipboard.online/tools/).

Source and setup: [`webclipboard/`](webclipboard/README.md).
