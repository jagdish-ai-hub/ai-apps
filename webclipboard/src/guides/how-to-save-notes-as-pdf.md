## Why save a note as a PDF

A note in a notepad is flexible but fragile. It lives in one browser, and if you send it as text it may lose its structure. A PDF fixes both problems. It is a self-contained file with the layout locked in: the heading is still a heading, the list is still a list, and it looks the same on a phone, a laptop and a printer. PDFs are also what most schools, offices and forms expect when they ask you to send something.

Saving a note as PDF is useful for meeting minutes you want to attach to an email, a study sheet you will print, a checklist for a trip, instructions for someone who will not open an app, or a record of a decision.

## How to do it from the online notepad

1. Open the [online notepad](/online-notepad/) and write your note. Add a title: it becomes the heading at the top and the name of the file.
2. Use the toolbar for bold, headings and lists. Press **Preview** to see the page as it will be printed.
3. Press **Download** and choose **PDF**.
4. Your browser opens its print window. Choose **Save as PDF** as the destination. Pick a page size if you are asked, and save.

If your note already has Markdown marks, such as a pasted answer with hashes and asterisks, they are turned into real formatting in the same way. For more control over fonts, page size and margins, use the [Markdown to PDF](/markdown-to-pdf/) converter, which has those options.

## Why the browser's PDF is a good choice

Many PDF tools draw text with a built-in font, and that font does not contain every language. Japanese, Chinese, Korean, Hindi, Thai and Arabic text either fails or needs a huge font file. When the browser makes the PDF, it uses the fonts already on your device, so every script prints, and the text stays real, selectable and searchable instead of becoming a picture.

The trade-off is the print window. It is one extra step compared with a one-click download, and its buttons look different in each browser. The result is a normal PDF you can attach, print or archive.

## Saving a PDF on a phone

The print window exists on phones too, though it looks different. On many Android phones, the print screen has a destination menu where you can choose **Save as PDF**. On iPhones, the print preview can be opened as a PDF and shared or saved to Files from the share button. The exact steps depend on your browser and system version, so if you do not see it at first, look for a share or save option in the print preview.

## Check before you save

Take a minute for a few checks. Use Preview to look at the structure, especially the headings and the lists. Make sure the title is the one you want, because it becomes the file name. Read the first and last lines, since notes often start or end in the middle of a thought. And remove anything private that should not be in a file you will send: once a PDF is out, you cannot take it back.

## When a Word file is better

Choose PDF when the document is final and should not change. Choose a Word file when the person receiving it needs to edit it, or when you want to keep working on it in Word or Google Docs. The same note can be downloaded either way; see [how to convert notes to Word](/guides/how-to-convert-notes-to-word/). To make a PDF from text that is not a note, the guide on [converting text to PDF](/guides/how-to-convert-text-to-pdf/) covers it.

## Common problems and quick fixes

**The PDF has extra blank pages.** This usually comes from a long note ending with blank lines. Remove the empty lines at the end and save again.

**The page looks different from the preview.** The preview shows the formatting, not the page breaks. Long notes are split into pages by your browser, and a heading can land at the bottom of a page. Adding a blank line before a heading usually moves it.

**The print window did not open.** Some browsers block it when the page is in a small embedded window, or an extension interferes. Open the page in a normal browser tab and try again, or allow pop-ups for the site.

**The file name is wrong.** The title becomes the file name. Change the title and save again, or rename the file after saving.

**Text is cut off at the edge.** Very long lines of unbroken text, such as a web address with no spaces, can run past the page. Break the line or use a shorter link.
