## Why save an answer as a PDF

A chat is a poor filing system. Answers scroll away, they are mixed with the rest of the conversation, and there is no neat way to hand one to a colleague who uses a different assistant. A PDF keeps one answer on its own pages. It looks the same on every device, it is easy to attach to an email, upload to a form or print, and it does not change when you open it a year later.

## Method 1: convert the answer (recommended)

The cleanest result comes from converting the answer's Markdown to a PDF with the [ChatGPT to PDF](/chatgpt-to-pdf/) tool:

1. Copy the answer. If the chat has a **copy** button under the answer, use it; it usually copies the Markdown, which keeps headings, lists and tables.
2. Paste it into the converter and check the preview.
3. Choose the font, size, page size and margins, and give the file a name.
4. Press **Save as PDF** and choose **Save as PDF** in the print window.

The PDF is made by your browser's own print function, so it uses the fonts on your device and the text stays **selectable and searchable**. Japanese, Chinese, Korean, Hindi, Arabic and other scripts print correctly. The text is processed in your browser, so a private conversation is not uploaded. The tool is independent and is not affiliated with OpenAI; it works with Markdown from any assistant.

## Method 2: print the chat page

Every browser can print a page to PDF. Open the conversation, press **Ctrl + P** (or **Command + P** on a Mac), choose **Save as PDF** as the destination and save. It is quick, but the result often contains menu bars or side panels, cuts tables and code across pages, and includes the whole conversation unless you scroll and select carefully. It is a fine way to keep a complete record, and a poor way to make a tidy document of one answer.

## Method 3: ask for a file

Some assistants can create a document for you if you ask, and some chat apps have an export option for conversations. What is available depends on the assistant and your plan, and the output varies. Treat it as an alternative to try, and open the file to check the formatting before sending it on.

## On a phone or tablet

On **Android**, use the browser's print option and choose **Save as PDF** as the printer. On an **iPhone or iPad**, choose **Print**, spread two fingers over the small page preview to open it as a full-size PDF, then use the share button and pick **Save to Files**. Copying the answer on a phone and sending it to your computer is easy with an [online clipboard](/): paste, note the code, and open it on the computer; the guide to [sending text from a phone to a PC](/guides/send-text-from-phone-to-pc/) has the steps.

## Making the PDF look good

- Choose a **serif font** for reports and a **sans-serif font** for notes and lists.
- Use **A4** or **US Letter** to match the paper you will print on, and **narrow margins** for wide tables.
- If a list or table does not look right in the preview, put a **blank line** before it in the pasted text; the preview updates as you edit.
- For a long answer with code, check that long lines wrap as you want before saving.

## What does not carry over

Images are shown as their alt text, because the converter never downloads pictures from other sites. Mathematical notation and syntax colours in code are not reproduced. If any of these matter, copy the answer into a word processor, add them, and export a PDF from there. If you want an editable file rather than a PDF, see [how to copy a ChatGPT answer into Word](/guides/how-to-copy-chatgpt-answer-into-word/).

## Privacy

Before you save or share a conversation, check it for names, passwords, business details and anything else you would not want to forward. A PDF is easy to share, which is a reason to make sure what is in it is meant to travel.
