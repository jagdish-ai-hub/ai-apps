## What "text to Word" really means

A text file contains only characters: no fonts, no page size, no margins. A Word document stores all of that. Converting text to Word therefore means choosing how the text should look (font, size, page, margins) and wrapping it in the **.docx** format that Word, Google Docs, LibreOffice and Pages all understand.

There are two situations. In the first, the text is already on the computer you are using and you can paste it straight into Word. In the second, the text is on another device or arrives as a message, an email or a chat answer, and you want a ready-made document without opening a word processor first.

## Method 1: paste into Word or Google Docs

If you have Word or a Google account, this is the most direct route:

1. Open a blank document.
2. Paste the text. To avoid carrying over odd styles from a web page, use **Paste as plain text**: **Ctrl + Shift + V** on Windows and Chrome OS, **Command + Shift + V** on a Mac, or the Paste Options button in Word and choose "Keep Text Only".
3. Pick a font and size, and set margins in the Layout (Word) or File, Page setup (Docs) menu.
4. Save as **.docx**.

This works, but it takes several steps, and on a phone the page layout controls are fiddly.

## Method 2: a browser converter

Open the <a href="/text-to-word/">Text to Word</a> tool, paste your text, pick a **font**, **size**, **page size** and **margins**, then press **Download Word file (.docx)**. The file is built in your browser, so the text is never uploaded, and it is a genuine .docx rather than a renamed text file.

Details worth knowing:

- Each line becomes a paragraph. Blank lines are kept as blank lines, and tabs are kept.
- The text is stored as Unicode, so Japanese, Chinese, Korean, Hindi, Thai, Arabic and Cyrillic text, and emoji, survive.
- The available fonts are common ones: Calibri, Times New Roman and Courier New. If a device lacks one, the word processor chooses a close match.
- There is no watermark and no account.

## Opening the file on any device

- **Word:** double-click it. If you see **Protected View**, click **Enable Editing**; Word shows this for any file downloaded from the internet.
- **Google Docs:** upload the file to Google Drive, right-click it and choose **Open with, Google Docs**.
- **Apple Pages and Mac:** open the file from Finder or the Files app; Pages converts it.
- **Phones and tablets:** the Word, Google Docs and Pages apps open .docx files directly from your Downloads folder or the Files app.

If you wrote the text on your phone and need it on a computer, the [online notes transfer guide](/guides/online-notes-transfer/) shows how to move it across with a code, then convert it on the larger screen.

## When the text is Markdown

Notes apps, developer tools and AI chat assistants often produce Markdown, where `# Title` means a heading and `**word**` means bold. Pasted as plain text into Word, those symbols stay visible. Use [a Markdown to Word converter](/guides/how-to-convert-markdown-to-word/) in that case, because it converts the symbols into real Word headings, lists and bold text.

## Tips for a clean document

- Remove extra spaces and double blank lines before converting; the converter keeps what you give it.
- Choose **A4** or **US Letter** to match the paper you will print on.
- For letters and reports use a serif font such as Times New Roman at 12 pt; for notes and lists use Calibri at 11 pt.
- Check the file in Word's **Print Preview** before sending it, because every word processor renders fonts slightly differently.
- If the recipient only needs to read the document, consider a PDF instead; the guide to [converting text to PDF](/guides/how-to-convert-text-to-pdf/) covers that.

## Keep private text private

Many "online converters" upload your text to a server. If your text is a draft contract, a medical note or anything personal, use a tool that converts in your browser, as the one above does, so no copy exists anywhere except your device. Delete the downloaded file when you have finished with it.
