## What goes wrong when you share a note the usual way

A note usually has structure: a title, a few headings, a list of things to do or to bring, some words in bold. The usual ways of sharing it each lose something. A chat app keeps the text but turns your list into plain lines, and any stars or hashes you typed for formatting stay as stars and hashes. Email keeps more, but a short note does not deserve a message with a subject line. A shared document keeps everything, but both of you need an account, and you have to set permissions for something you wanted to hand over in ten seconds.

What you want is simple: the note arrives on the other person's screen looking the way you wrote it, with no sign-up for either of you.

## Four ways to share a note, compared

**Chat message or email.** Fast and familiar. The text arrives, but formatting often does not, long notes get hard to read, and the note stays in the conversation forever. Good for plain, short text.

**Shared document.** Best when several people edit the same thing over time. It needs accounts and permission settings, and it keeps a copy you may not want to leave around. Not great for a quick hand-off.

**A file attachment.** A Word file or PDF keeps formatting, but making one and attaching it takes steps, and the receiver has to download and open it.

**A code or link to a formatted note.** You paste the note, get a 6-digit code, a link and a QR code, and send whichever suits. The receiver opens it in a browser and sees the formatted note. It expires on its own. This is the fastest route for a hand-off, and it is what [Share Notes Online](/share-notes-online/) does.

## How to share a note with a code, step by step

1. Write the note, or paste it. Use the toolbar for bold, headings and lists, and press Preview to check how it looks.
2. Pick how long it should stay available, from ten minutes to seven days. Shorter is safer.
3. For anything private, add a password, or choose to delete it after it is opened once.
4. Press Save. You get a code, a link and a QR code.
5. Send the code or link, or let the person scan the QR code from your screen. On their device they open the link, or open the site, choose to receive, and type the code.

If you wrote the note in the [online notepad](/online-notepad/), the Share this note button opens the share page with your note already filled in.

## Keeping a shared note private

Anyone who has the code can read an unprotected note until it expires, so treat the code like a link to a document. A few rules keep you safe.

- **Use a password for anything private.** The note is encrypted in your browser before it is sent, so the server only holds unreadable data. Give the password to the person another way, not in the same message as the code.
- **Use a short expiry** and delete after first view for one-time information.
- **Never share secrets.** Passwords, card numbers, recovery codes and private keys do not belong in a note. If you must pass a password to someone, read [how to share passwords safely](/guides/how-to-share-passwords-safely/).
- **Share the code carefully.** In a group chat, everyone in the group can use it.

## When to use something else

A code-based note is for hand-offs, not for collaboration or storage. It is read only, it expires after at most seven days, and there is no history or account. If you and others need to edit the same text, use a shared document. If you need to keep the note, keep the original in your notepad or download it as a file.
