## Why convert a note to Word

A note is meant to be fast. A Word document is meant to be shared, printed, edited by others and kept. Some notes grow into documents: meeting minutes that need to go to the team, a study outline that becomes an essay, a checklist that turns into a procedure, a draft you want to polish with spelling tools and comments. When that happens, the worst way to move the text is to copy and paste it into Word and then fix every heading and list by hand.

Converting the note keeps its structure. The title is still a title, the headings are real headings that appear in Word's navigation pane, the bold text is bold, and the lists are real lists that you can restyle.

## How to do it from the online notepad

1. Open the [online notepad](/online-notepad/) and write your note. Give it a title; it becomes the heading and the file name.
2. Format it with the toolbar: bold, italic, a title and headings, bullet and numbered lists, checklists. Press **Preview** to check.
3. Press **Download** and choose **Word (.docx)**.
4. Open the file in Word, Google Docs, LibreOffice or any editor that reads .docx.

For more options, such as the font, size, page size and margins, use the [Markdown to Word](/markdown-to-word/) converter. It reads the same marks the notepad writes.

## What turns into what

The notepad stores your note as plain text with simple marks, and the converter maps each mark to a Word feature. Two asterisks around a word become bold. A hash at the start of a line becomes a heading, and two hashes a smaller heading. A dash makes a bullet, a number and a dot make a numbered list, and a dash followed by square brackets makes a checklist line. Blank lines separate paragraphs.

You never have to type these marks if you do not want to. The toolbar adds them. Knowing them helps when you paste text from somewhere else, such as an answer from an AI assistant, because the same marks work. For that case, see [how to convert Markdown to Word](/guides/how-to-convert-markdown-to-word/).

## Tips for a clean document

- **Start with a title.** It sets the file name and the top heading, so the document is easy to recognise in a folder.
- **Use headings rather than bold lines.** Real headings let Word build a navigation pane and a table of contents, and let others jump around.
- **Keep lists for lists.** Items that belong together should be one list, not several single-item lists.
- **Check the preview.** If it looks right there, it will look right in Word.
- **Rename the file** if you need a specific name for a form or a handover.

## After the download

The Word file is yours. Open it, adjust the font, add page numbers, insert a table or comments, and send it as you would any document. If you also need a copy that nobody can edit, save the same note as a PDF; see [how to save notes as a PDF](/guides/how-to-save-notes-as-pdf/).

Remember that the original note is still in the notepad, in the browser where you wrote it. The Word file is a separate copy, and changes you make in Word do not flow back to the note. If you keep working in the notepad after downloading, download again to get a new version.

## Common questions after converting

**Why does my list look different from the one I typed?** The note stores the list with simple marks, and Word draws its own bullets and numbers. The structure is the same; the look follows Word's style for lists, which you can change in one step for the whole list.

**Can I change the font afterwards?** Yes. The file uses a standard font, and you can select all and choose any font and size. If you want a particular font before you download, use the [Markdown to Word](/markdown-to-word/) converter, which has font, size, page size and margin options.

**What about images and tables?** The notepad is for text. If you need pictures, add them in Word after downloading. Simple tables written in Markdown are converted when you paste them into the Markdown to Word converter.

**Does the file contain anything hidden?** No. It holds the text and formatting of your note and the document settings for the page. It does not contain the note's history or any information about your device.
